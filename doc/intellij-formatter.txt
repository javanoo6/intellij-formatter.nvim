*intellij-formatter.txt*  IntelliJ-powered formatting through conform.nvim

Requirements: Neovim 0.10+, conform.nvim, JDK 21.

SETUP                                          *intellij-formatter-setup*
>
    require("intellij-formatter").setup({
      java = "java",
      -- jar = "/path/to/formatter-cli-full.jar",
      -- editorconfig = "/path/to/.editorconfig",
      daemon = true,
      timeout_ms = 30000,
      auto_install = true,
      install_timeout_ms = 240000,
      optimize_imports = true,
      rearrange = true,
      format_on_save = false,
      conform = true,
      notify = true,
    })
<
By default, setup registers the supported filetypes with Conform and disables
their LSP fallback. Other filetypes retain their configured formatters.
Set filetypes = { "java", "python" } to select a subset. Repeated setup restores
routes previously replaced by this integration, preserving later user overrides.
There are no default keymaps. Configure your own mapping or use the commands.
The first formatting request automatically downloads and verifies the engine,
then continues formatting. No install command is required. Concurrent requests
share the download. Buffer edits made while waiting are preserved by discarding
the older request. Cached installations work offline. Set auto_install = false
to prevent automatic downloads, or jar to use an existing local build.

COMMANDS                                       *intellij-formatter-commands*

:IntellijFormat                                *:IntellijFormat*
    Format the current buffer asynchronously. Accepts a line range. Java import
    cleanup and rearrangement apply only to full-file requests. Range selection
    filters Conform diff hunks; an intersecting hunk may include adjacent lines.

:IntellijFormatterInstall[!]                    *:IntellijFormatterInstall*
    Optionally download and SHA-256-verify the engine ahead of first use.
    Requires curl plus sha256sum, shasum, openssl, or certutil. Bang forces a
    redownload. Failed installation preserves the previous JAR. A configured
    local jar is never replaced by this command.

:IntellijFormatterInfo                          *:IntellijFormatterInfo*
    Display JAR, Java, EditorConfig, filetypes, and format-on-save configuration.

:IntellijFormatterStop                          *:IntellijFormatterStop*
    Stop the formatter engine's reusable background daemon.

:checkhealth intellij-formatter
    Check Neovim, Java, Conform, engine, and installation tools.

API                                            *intellij-formatter-api*
>
    local formatter = require("intellij-formatter")
    formatter.format({ bufnr = 0, async = false }, function(err, did_edit) end)
    formatter.install({ force = false }, function(err, path) end)
    formatter.stop(function(err) end)
    formatter.conform_formatter() -- Conform formatter definition.
    formatter.available()         -- Boolean, optional error string.
    formatter.ensure(function(err, path) end) -- Automatic installation if needed.
    formatter.timeout()           -- Includes first-install allowance when needed.
    formatter.filetypes()         -- Copy of configured filetype list.
    formatter.supports("yaml")     -- Boolean.
    formatter.jar_path()          -- Active JAR path.
    formatter.options()           -- Copy of current setup options.
    formatter.info()              -- Printable configuration report.
<
Set conform = false and use conform_formatter() in your own Conform setup for
manual integration. Default formatting timeout is 30 seconds to allow cold JVM
startup and initial engine extraction. It can be reduced for a warmed daemon.
The first install gets an additional 240-second allowance. Explicit timeouts in
your own Conform calls override this; use formatter.timeout() to inherit it.

EDITORCONFIG                                   *intellij-formatter-editorconfig*

Omit editorconfig to discover settings from each file. An explicit path (or
function of Conform's context returning a path) selects a config root even for
external files. Shell formatting uses bundled shfmt and its EditorConfig options.

LIMITATIONS                                    *intellij-formatter-limitations*

Python import cleanup is not supported. Helm templates are excluded; ordinary
YAML Helm values are supported. Whitespace paths use one-shot mode to work around
the engine's daemon protocol. The engine download is about 347 MiB and extracts
a larger runtime into the system temporary directory. It installs on first use
unless auto_install is disabled or a custom jar is configured. The integration
is validated on Linux; other hosts are untested.
